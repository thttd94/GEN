V2.2 full-system snapshot is not embedded in Git main tarball to avoid filling router /root during online install.

Required full snapshot files after creating/restoring a local full backup:
- system/etc_config.tgz
- system/etc_crontabs.tgz
- system/etc_genrouter.tgz
- system/etc_init_d.tgz
- system/etc_rc_local.tgz
- system/etc_shm.tgz
- system/opt_proxy_manager_v1.tgz
- system/system_manifest.txt

Create on a known-good router:
  sh /opt/proxy-manager-v1/full_system_backup.sh 2.2

Rollback on the same/router with local backup:
  sh /opt/proxy-manager-v1/rollback_version.sh 2.2

Note: Git online install seeds the lightweight package only. Full system snapshots live under /data or /root genrouter_backups and must not be packed into the Git tarball.
